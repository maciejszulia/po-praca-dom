# po-praca-dom

Object-oriented programming homework in Java: a program based on an example from the textbook "Java. Podstawy" (Horstmann, Cornell) that reads words into a set and measures the time; the original note compares HashSet and TreeSet.

University coursework from my Computer Science studies at UWM (2020–2024). I wrote the code by hand; the commit history is unchanged. This README was added in November 2026.

Years of work: 2021 (commits on 13 December 2021).

## Contents

- `src/WordsInHashSetDemo.java`: reads words from standard input into a set, prints 20 of them, the number of unique words and the time in milliseconds.
- `src/alice30.txt`: "Alice in Wonderland" from Project Gutenberg, used as input.

## Running

The code needs a Java compiler (JDK), which this machine does not have, so I did not run it in November 2026.
